# PDF 图表转矢量 · Figure → SVG

把论文里的图表从 PDF 里框选出来，交给视觉模型重绘成可编辑的 SVG，可单页生成、批量生成、打包下载。

## 三步用法

1. **起代理**：双击 `start-proxy.bat`。它会用 Python 起一个本地 CORS 代理，默认监听 `http://127.0.0.1:8787`，上游默认 `http://10.17.121.224:3425`。
   换网关：`start-proxy.bat http://你的网关:端口`，或命令行 `python proxy.py --upstream http://你的网关:端口`。
2. **打开页面**：直接双击 `index.html`（`file://` 打开即可，不需要 Web 服务器）。
3. **填设置**：右上角「模型设置」→ 点「一键切换到本地代理（8787）」（页面会自动探测）→ 填 API Key 与模型名 → 保存。
   然后上传 PDF、框选区域、点「生成 SVG」。

## 模型要求

- 必须是**能输出 SVG 正文的视觉模型**（能读图片、能按要求返回 `<svg>`）。
- **不要用 reasoning / 思考型模型**：它们的 `reasoning_content` 会吃掉全部 max_tokens，正文为空并触发熔断。
- 网关若把模型别名路由到别的模型，页面会提示「模型路由不一致」，设置里能看到「上一次实际使用的模型」。
- 不确定能不能用，先点设置里的「模型探测」（只花 24 + 32 tokens）。

## 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| `Failed to fetch` / CORS | 网关没回 CORS 头或拦了 OPTIONS 预检。用 `start-proxy.bat` 起本地代理，Base URL 填 `http://127.0.0.1:8787/v1`。 |
| `502` + 代理 JSON 文案 | 本地代理等不到上游。确认网关地址/端口/VPN；生成慢就把 `proxy.py --timeout` 调大（默认 600 秒，最小 10 秒）。 |
| 预算不足 / `finish_reason=length` | 页面会按 4096 → 8192 → 16384 自动加码，同一次任务所有层复用新预算。仍不够就换模型，别继续加。 |
| 只返回思考内容（熔断） | 该模型只产 reasoning、不产正文。换支持 SVG 输出的视觉模型，或在网关关闭 reasoning。 |

## 文件清单

| 文件 | 说明 |
| --- | --- |
| `index.html` | 单文件应用（UI、pdf.js 调用、请求与诊断都在里面） |
| `proxy.py` | 零依赖本地 CORS 代理（仅 Python 标准库，Python 3.8+） |
| `start-proxy.bat` | Windows 启动器：找 Python、起代理、端口自动顺延 |
| `vendor/pdf.min.js` | pdf.js 主库（本地，无 CDN 依赖） |
| `vendor/pdf.worker.min.js` | pdf.js worker（必须与 index.html 同级 vendor 目录） |

> API Key 只存在浏览器 localStorage，不会上传到任何第三方服务器。

## 结果面板

右侧「结果」顶部是结论卡：状态（成功 / 失败 / 熔断 / 回退）+ SSIM、对齐后 MAE、耗时三个数字 + 实际模型 / 档位 / 请求次数。
下面「指标详情 / 图元识别 / 请求明细 / 诊断」四组默认只展开一组，标题右侧有摘要；面板可拖左边界调宽、可整体收起，宽度与折叠状态会记住；窄屏（<1180px）自动移到下方。

> 程序图元为实验特性，默认关闭，开启后会自动做质量门控（叠加后 SSIM 不升就自动退回模型结果）。
